# Notebooks (Task 1: Data & EDA)

This directory contains Jupyter notebooks for interactive analysis of oil price data.

## Files

- **`oil_price_analysis.ipynb`**: The main analysis notebook for Task 1. It covers:
  1. **Data Loading**: Reading and cleaning `BrentOilPrices.csv`.
  2. **EDA**: Visualizing price trends, distributions, and volatility.

## Usage

To run the notebook:

1. Ensure you have installed the requirements:
   ```bash
   pip install -r ../requirements.txt
   ```

2. Start Jupyter Notebook or Lab:
   ```bash
   jupyter notebook
   ```

3. Open `oil_price_analysis.ipynb` and run the cells sequentially.

## Note on Imports

The notebook is configured to import modules from the `../src` directory automatically. You do not need to install the package if you run the notebook from this directory.
